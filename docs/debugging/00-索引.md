## 通用调试心法(从这 16 个问题里提炼)

1. **先复现再修**,永不凭症状猜;系统分四层:预处理→抽取→数据质量→比对,逐层打日志找断点。
2. **LLM 参与的部分必须有"空转探针"**:抽 0 条、复核 0 条、解析失败要显式上报,不许静默降级。
3. **确定性校验是兜底,不是可选项**:去重、1:1 唯一性、派生约束(MAC←追溯码)都要硬校验,LLM 是增强不是依赖。
4. **捕获组约定是生命线**:每个字段的 regex/context_anchor 必须有包住"值"的括号,否则取到标签。
5. **平台是真值源**:平台原生格式(.xls)为准,杜绝"中间转换"造成表头漂移;日志字段可能有头码/尾码。
6. **生产数据不进 git**:见 08 篇附录。
7. **缺值不等于可以抓邻居**:任何字段缺失时,"就近绑定"兜底会偷到窗口内最近的其他设备值——先保证每字段有值,再谈就近;粘连/脏值形态要先实测确定"取第几个完整号"(如粘连 ICCID 最后一个才是真值)。
8. **绑定优先锚点后不是全局默认**:SN 在锚点前(发指令型 A02SG/A02EG/A02FG)还是锚点后(读回型 F16G)取决于设备固件;绑定方向必须设备配置化 `sn_direction`/`iccid_direction`(详见 14/16 篇)。
9. **新设备配置必须双形态抽样**:配置上线前 100 行抽样,统计关键字段形态频次,频次 > 0 的全部进 keep_patterns + regex(详见 11 篇)。
10. **LLM 兜底边界**:LLM 是 Layer 2 兜底,不是 Layer 1 替代;已知形态一律正则解决。
11. **跨文件 = 跨日期 = 跨逻辑墙**:HH:MM:SS 无日期时,任何依赖时间窗的逻辑都不能跨文件,SN/ICCID/MAC 绑定必须按文件隔离(详见 12 篇)。
12. **追溯码前缀是"家族码+批次变体",不是稳定字面量**:写正则前先扫平台 CSV 全部唯一前缀分布;家族常量保留(隔离同族产品),变体段用 `{n}` 放宽,且**同族全部设备都要扫**(详见 13/16 篇)。
13. **hex 字段去重必须有 hex 意识**:`8986` marker 对 hex ICCID 危险(内部可能天然含 8986),按字段格式收集,禁用 `s[first:second]` 截断(详见 14 篇)。
14. **日期段/批次段是另一类「批次变体」**:SN 里日期码(2402606/7/8)随生产批次变,regex 与 keep_patterns 都要 `{n}` 放宽,不能硬编码某月(详见 16 篇)。
15. **keep_patterns 与 regex 必须同步放宽**:只改抽取 regex 不改 keep_patterns,SN 行在 preprocessor 就被丢(详见 16 篇)。
16. **有派生关系就开 MAC 派生绑定**:MAC←追溯码末段(实测 100%)应开 mac_derived_from_trace,时间窗就近在慢速板检+窗口重叠时偷邻居(详见 16 篇)。
