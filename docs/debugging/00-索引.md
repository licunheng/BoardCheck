## 通用调试心法(从这 10 个问题里提炼)

1. **先复现再修**,永不凭症状猜;系统分四层:预处理→抽取→数据质量→比对,逐层打日志找断点。
2. **LLM 参与的部分必须有"空转探针"**:抽 0 条、复核 0 条、解析失败要显式上报,不许静默降级。
3. **确定性校验是兜底,不是可选项**:去重、1:1 唯一性、派生约束(MAC←追溯码)都要硬校验,LLM 是增强不是依赖。
4. **捕获组约定是生命线**:每个字段的 regex/context_anchor 必须有包住"值"的括号,否则取到标签。
5. **平台是真值源**:平台原生格式(.xls)为准,杜绝"中间转换"造成表头漂移;日志字段可能有头码/尾码。
6. **生产数据不进 git**:见 08 篇附录。
7. **缺值不等于可以抓邻居**:任何字段缺失时,"就近绑定"兜底会偷到窗口内最近的其他设备值——先保证每字段有值,再谈就近;粘连/脏值形态要先实测确定"取第几个完整号"(如粘连 ICCID 最后一个才是真值)。
8. **绑定优先锚点后**:失败循环的上一台设备旧值恰在锚点之前,"就近"会偷过来;SN/id 这类 trace 之后才读回的字段,应强制「锚点之后优先」。
