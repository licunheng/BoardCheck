板检数据核验工具
=====================

一、这是什么
  对比"板检原始日志"与"追溯平台导出的 CSV",自动生成三份报告:
    - 对比表(.xlsx)  详细逐设备字段对比
    - 重传数据(.csv)  需要人工补录/重传的记录
    - 分析报告(.md)  汇总 + 原因分析 + 修复建议

二、环境要求
  - 本工具为单文件程序,已内置 Python 运行环境,【无需安装 Python 或 Node.js】。
  - 仅需 Windows 系统(Windows 10 / 11)和任意浏览器(Edge / Chrome 均可)。
  - 安装包本身也无需任何运行环境,双击即可安装。

三、安装
  双击"板检数据核验工具-安装包.exe",按提示解压,即自动安装到
  %LOCALAPPDATA%\板检数据核验工具\,并创建桌面快捷方式、自动启动。
  若杀毒软件询问,请选择"允许"。

四、使用
  1. 双击桌面"板检数据核验工具"快捷方式
  2. 浏览器自动打开 http://127.0.0.1:5050
  3. 依次:选设备型号 -> 上传板检日志 -> 上传平台 CSV -> 开始核验 -> 下载报告

五、支持的产品型号
  内置:A02EG / A02SG / F16G
  新增型号:把新的 4 个配置文件(device.json / extraction_rules.json /
  filter_rules.json / prompts.md)放到安装目录 devices\<型号>\ 下,重启即可,
  无需重新安装。

六、常见问题
  - 双击后浏览器没自动打开:手动访问 http://127.0.0.1:5050
  - 端口被占用:关闭其他占用 5050 的程序后重试
  - 需要 LLM 智能复核:在页面"LLM 设置"中填写 API Key(可选,不填也能用)
